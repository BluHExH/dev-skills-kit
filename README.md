# Dev Skills Kit

A high-quality collection of **skills** for Web Developers and Software Developers.

These skills are designed to be used with AI agents (like Grok) to provide specialized, consistent guidance on common professional development tasks.

## Skills Included

### 1. Web Development
- **modern-frontend-workflow** — React, Next.js, Tailwind, component design & best practices
- **backend-api-design** — REST/GraphQL API design, structure, auth, error handling
- **fullstack-project-structure** — Monorepo & single-repo folder conventions
- **web-performance-seo** — Core Web Vitals, performance optimization & SEO

### 2. Software Development
- **clean-code-practices** — Naming, function design, refactoring, maintainability
- **git-workflow-code-review** — Conventional commits, branching, PR & review process
- **testing-and-debugging** — Test strategy + systematic debugging approach

### 3. Professional / Client Work
- **client-work-workflow** — Requirement gathering, estimation, proposals, communication & delivery

### 4. Productivity
- **developer-productivity** — Task management, deep work, learning systems & portfolio

## How to Use

Each skill lives in its own folder and contains a `SKILL.md` file.

You can import these into compatible AI agent systems or use them as reference documentation for your own workflow.

dev-skills-kit/
